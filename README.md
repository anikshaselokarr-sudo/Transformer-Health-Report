# streamlit learning
Description

This project is a Streamlit Demo Application that showcases the most commonly used Streamlit widgets and features for building interactive web applications in Python. It demonstrates how to collect user input, upload and display CSV files, create forms, display text and media, and organize content using Streamlit components.

Features
👋 Greeting users with text input
📂 Upload and display CSV files using Pandas
📝 Text input, text area, and number input widgets
🎚️ Slider, select box, multiselect, radio button, and checkbox examples
📊 Conditional content display
🔐 Simple login form with form submission
🖼️ Display images
🎥 Embed YouTube videos
📑 Headers, subheaders, Markdown, and code snippets
📌 Sidebar navigation
Technologies Used
Python
Streamlit
Pandas
Purpose

This application is designed for beginners who want to learn the basics of Streamlit and understand how to build interactive data applications with minimal code. It serves as a starting point for developing dashboards, data visualization tools, and AI-powered web applications.
